# Quote-Generator
A website where you can generate motivational quotes
<hr>
<h3>Features</h3>
<ul>
  <li>Various quotes that can be generated with a button</li>
  <li>A typewrite effect on the quotes</li>
  <li>A box that flows up and down</li>
  <li>A custom mouse image + a glitter trail to follow it</li>
  <li>Calming music that can be muted/unmuted (please note autoplay doesn't work on all browsers - you may have to start it by clicking on the screen)</li>
</ul>
